Preprocessing steps for text data:
1. Convert all alphabets to lower
2. Remove HTML tags and url
3. Remove imoji or describe it
4. Remove all punctuation marks
5. Replace short forms like (btw)
6. Word correction with TextBlob
7. Remove stopwords with (nltk.corpus.stopwords)
8. Tokenize
9. Stemmer or Lemmatization(Transform verbs to root form)
